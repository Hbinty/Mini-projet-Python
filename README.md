# Mini-projet-Python - Gestion des Employés

## Description du projet
Ce mini-projet consiste à manipuler et analyser des données d'employés.  
Le programme lit les informations des employés et permet de générer des statistiques simples telles que :  
- Répartition par sexe  
- Répartition par type de contrat  
- Répartition par grade  

L'objectif est de se familiariser avec la lecture de fichiers, le traitement de données et l'utilisation de bibliothèques Python pour l'analyse.

## Technologies utilisées
- Python 3.14
- Collections (Counter)
- CSV 
- Matplotlib
- Git/Github

## ▶️ Instructions d’exécution

1. Cloner le dépôt :
```bash

2. Accéder au dossier du projet:

cd Mini-projet-Python

3. Installer les dépendances :

4. Lancer le programme :
